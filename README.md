# royaassigment2-layout

The university’s Office of Student Engagement needs a small website that helps students discover campus activities.

Campus Event Guide - Programmer University

Project Description
--------------------
This website is a campus event guide for Programmer University. It helps students find upcoming events, view event details, and learn about activities happening on campus. The site includes a home page with multiple event cards and a featured event details page.

Layout Decisions
----------------
Flexbox was used for the header, navigation, and footer. It helped keep the items aligned and spaced evenly across the page.

CSS Grid was used for the event cards on the homepage and for the main content and sidebar layout on the event details page. It helped organize the content into columns and made the design look clean and easy to read.

Responsive Design
-------------------
The website uses a mobile breakpoint at 767px. Below this width, the layout stacks into a single column so the content stays easy to read on smaller screens.

Semantic HTML
--------------
header: used for the top section of the page  
nav: used for the navigation links  
main: used for the main content of the page  
footer: used for the bottom section of the page
